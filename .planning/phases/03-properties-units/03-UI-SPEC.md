# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3: Properties & Units.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Scope note (CONTEXT overrides ROADMAP success criteria):** Phase 3 UI covers property/unit CRUD, tags, custom statuses, S3 gallery, Mapbox address, TipTap notes, soft-archive, and PlanLimitGate. Explicitly **out of UI**: PROP-03 stats/alerts strip, PROP-04/05 lease-expiry alerts, live UNIT-03/04 history (stub empty tabs only), UNIT-05 proration.

## Spacing Scale

Standard 8-point scale. All values are multiples of 4. Inherit Phase 2.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`) | Icon gaps, tag chip icon-to-label |
| sm | 8px (`gap-2`, `p-2`) | Compact chips, gallery tile padding, helper text offset |
| md | 16px (`px-4`, `gap-4`) | Default form field spacing, card content gaps |
| lg | 24px (`px-6`, `gap-6`) | Card padding (Card default), section gaps on detail pages |
| xl | 32px (`gap-8`) | Between major detail sections (Overview / Gallery / Units) |
| 2xl | 48px (`py-12`) | Empty-state vertical breathing room |
| 3xl | 64px (`py-16`) | Rare — full-page empty when list has zero items |

Custom tokens (already in globals.css):
- `--spacing-navbar: 4rem` — top bar
- `--spacing-page` / `--page-padding: 1rem`
- `--content-padding: 2rem` — main content horizontal padding inside app shell

Exceptions:
- Minimum touch target for icon-only buttons: **40px** (`size-10`) — gallery remove, reorder handle, tag remove chip ×
- Property card cover image height: **160px** (`h-40`) — fixed crop, not a spacing-scale value
- Gallery tile: **96×96px** (`size-24`) grid cells; drag handle overlay inset 4px
- Archive confirm name-input: full width inside Dialog, not a custom spacing token

## Typography

Same contract as Phase 2. Inter for UI; Gambetta only for Villuh wordmark in chrome.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 | Form descriptions, address lines, empty-state body, toast copy, table cells |
| Label | 14px (`text-sm`) | 500 (medium) | 1.4 | Field labels, nav items, button text, tag chip labels, status badges |
| Heading | 16px (`text-base`) | 500 (medium) | 1.2 | Card titles, dialog titles, section headings, property card name |
| Display | 24px (`text-2xl`) | 500 (medium) | 1.1 | Page titles only (`Properties`, `Units`, property detail name) |

Notes:
- Two weights only: **400** and **500**. Do not introduce `font-semibold` / 600.
- `font-heading font-medium` for CardTitle / DialogTitle — matches existing components.
- TipTap rendered notes: body role inside prose container; headings inside editor map to TipTap H2/H3 at `text-base` / `text-sm` medium — not Display.

Source: Phase 2 UI-SPEC, `packages/ui/src/card.tsx`, `apps/landlord-web/app/layout.tsx`

## Color

Use semantic Tailwind tokens — never hardcode OKLCH in components.

| Role | CSS Token | Light Value | Usage |
|------|-----------|-------------|-------|
| Dominant (60%) | `--background` | `oklch(1 0 0)` | App main area, list pages, form pages |
| Secondary (30%) | `--card` / `--sidebar` | `oklch(0.987 0 0)` / `oklch(0.985 0 0)` | Property cards, detail section cards, sheets, dialogs, sidebar |
| Accent (10%) | `--primary` | `oklch(0.21 0.006 285.885)` | Primary CTAs only (see reserved list) |
| Destructive | `--destructive` | `oklch(0.577 0.245 27.325)` | Archive confirm CTA, permanent image delete, destructive menu items |
| Muted text | `--muted-foreground` | `oklch(0.552 0.016 285.938)` | Placeholders, empty states, address secondary line, unit count snippet |
| Ring / Focus | `--ring` | `oklch(0.705 0.015 286.067)` | Focus-visible rings |
| Border | `--border` | `oklch(0.92 0.004 286.32)` | Inputs, separators, gallery tile rings |
| Success | `--success` | `oklch(0.46 0.15 141.3)` | Optional success toast icon only — not status badge fills |

Accent (`--primary`) reserved for:
1. Page primary create CTAs: **Add property**, **Add unit**
2. Form submit CTAs: **Save property**, **Save unit**, **Create property**, **Create unit**
3. LimitReachedDialog primary: **View billing plans**
4. Cover / first-image indicator ring on gallery when selected as cover (`ring-2 ring-primary`)

**Not** accent: tag chip colors, status badge colors, Mapbox suggestion hover (use `bg-muted`), TipTap toolbar active state (use `bg-muted` / `text-foreground`).

## Screens and Interaction Contracts

### Screen 1: Properties list `/properties`

**Layout:** App shell (sidebar + navbar). Page header row: Display title **Properties** left; primary CTA right wrapped in `PlanLimitGate` resource=`properties`.

**List:** Responsive **card grid** (D-09) — `grid gap-4 sm:grid-cols-2 xl:grid-cols-3`. Not a dense table as primary.

**Property card** (Claude discretion — locked):
- Cover: first gallery image or muted placeholder (`bg-muted`, centered `IconBuildings` 32px)
- Title: property name (Heading)
- Secondary: single-line address (`city, region` or street) — Body muted, truncate
- Tag chips: up to **3** chips (icon+label); if more, `+N` muted chip
- Footer snippet: `{unitCount} units` — Body muted (not PROP-03 occupancy/rent/alerts)
- Entire card clickable → property detail; hover: slight `shadow-md` intensify / `ring-foreground/10`

**Empty state:** see Copywriting Contract.

**Loading:** 6 `Skeleton` cards matching grid.

**Actions:**
- Primary: **Add property** — `Button` default — PlanLimitGate intercept if at quota
- No bulk actions in Phase 3

---

### Screen 2: Create / Edit property `/properties/new` · `/properties/[propertyId]/edit`

**Layout:** App shell. Breadcrumbs: Properties → Add property / Edit. Max content width `max-w-2xl`.

**Why page (not Dialog):** Mapbox + TipTap + gallery need vertical space; Dialog would scroll poorly.

**Fields (order):**
1. Name — Input, required
2. Address — Mapbox autocomplete Input → on select fills structured fields; always show expandable structured fields: street, line2 (optional), city, region, postal, country (D-11, D-22–D-25). Manual entry always available if Mapbox fails.
3. Phone — Input tel, optional (D-12)
4. Tags — Combobox/multi: freeform create + org catalog suggestions; chip display with icon+color; promote affordance when freeform + `write` permission (D-17–D-19)
5. Notes — TipTap editor, optional; placeholder **Add notes…** (D-13–D-16); toolbar: Bold, Italic, Bullet list, Numbered list, Link, Heading (H2/H3 only)
6. Gallery — only on **edit** (or after create on detail); create page may omit upload until property exists, OR upload after first save — prefer: gallery section on detail + edit, not on first create form (keeps create fast). If product wants images on create, upload after property id exists in same session.

**Actions:**
- Primary create: **Create property** → navigate to property detail (D-08)
- Primary edit: **Save property**
- Secondary: **Cancel** → `Button` outline → back to list or detail

**States:** Field errors via `Field` + `aria-invalid`; server errors `toast.error`; success `toast.success` then navigate/invalidate.

---

### Screen 3: Property detail `/properties/[propertyId]`

**Layout:** App shell. Breadcrumbs: Properties → {name}. Page header: Display name + actions menu.

**Sections (vertical, gap-xl) — NO stats/alerts strip (D-05):**
1. **Overview card** — address block, optional phone, tag chips, notes (rendered sanitized HTML/markdown output)
2. **Gallery** — reorderable grid; first tile = cover badge “Cover”; add images; max 25; per-file 10MB; JPEG/PNG/WebP/GIF (HEIC if practical) (D-34–D-38)
3. **Units** — nested unit list (table or compact rows) + **Add unit** (PlanLimitGate resource=`units`)

**Header actions:**
- **Edit** — outline → edit page
- **Archive property** — ghost-destructive → Archive confirm Dialog (D-30–D-33)

**Gallery interactions:**
- Drag-reorder updates order; index 0 = cover (D-35)
- Remove image: immediate confirm micro-dialog or inline confirm — immediate S3+DB delete (D-37); CTA destructive **Remove photo**
- Upload: multi-file; show per-file progress; reject oversize with toast

**Not shown:** total occupancy %, monthly rent total, lease alerts (deferred PROP-03/04/05).

---

### Screen 4: Units list `/units`

**Layout:** App shell. Title **Units**. Primary CTA **Add unit** behind PlanLimitGate.

**List:** Table (units are denser than properties) — columns: Unit label, Property (link), Status badge, Base rent, Sq ft, Actions.

**Filters (minimal):** optional property filter Select; optional status filter — if cheap; else ship unfiltered v1.

**Empty state:** see Copywriting.

**Create unit:** opens **Sheet** (right, `sm:max-w-md`) with property **Select/Combobox** required (D-10), then unit fields.

---

### Screen 5: Unit create / edit (Sheet)

**Fields:**
- Property — required Select (locked when opened from property detail)
- Label — required Input
- Square footage — optional number Input
- Base rent — required currency Input, prefix `$`
- Status — Select of org statuses, Badge preview (D-26–D-29); assignment **manual** in Phase 3

**Actions:** **Create unit** / **Save unit** primary; **Cancel** outline closes Sheet.

**From property detail:** same Sheet, property prefilled + disabled.

---

### Screen 6: Unit detail `/units/[unitId]`

**Layout:** App shell. Breadcrumbs: Units → {label} (and/or Properties → {property} → {label}).

**Header:** Label (Display) + Status badge + property link + **Edit** + **Archive unit**.

**Body tabs** (install shadcn `tabs`):
1. **Overview** — label, property, sq ft, base rent, status
2. **Rent history** — stub empty (D-04)
3. **Tenant history** — stub empty (D-04)

No fake rows. Empty copy per Copywriting Contract.

---

### Screen 7: Org tag catalog (settings or property-adjacent)

**Placement:** Manage via tag picker “Manage tags…” → Dialog/Sheet listing org catalog tags (icon, color, name). Create/edit/delete requires `write` (D-18–D-19).

**Delete in-use tag:** confirm Dialog — cascade detach + delete (D-20); copy in Destructive Actions.

**Promote freeform:** on property tag chip overflow menu — **Save to organization tags** when `write`.

---

### Screen 8: Unit status catalog (owner/admin only)

**Placement:** Units page overflow or Settings subsection **Unit statuses**. Owner/admin only (D-27): create, rename, reorder, archive statuses. Seeded three defaults non-deletable rename-ok; archive custom only if unused or reassign — product: allow archive with reassignment prompt if needed; minimum: prevent archive of status still assigned (toast error).

**UI:** ordered list with drag-reorder; each row color+icon+label; **Add status** button.

---

### Persistent UI: PlanLimitGate + LimitReachedDialog (D-39–D-43)

**PlanLimitGate:** Wraps create triggers (`Add property`, `Add unit`). Reads `me.get` → `org.quota.{properties|units}`. If `count >= limit`, click opens LimitReachedDialog instead of create page/Sheet — never flash empty create UI.

**LimitReachedDialog** (`Dialog`, `sm:max-w-md`) — align Phase 2 upgrade modal:
- Title: **You've reached your {resource} limit**
- Body: `{action} isn't available on your plan. You're using {count} of {limit} {resource}.`
- Footer: **View billing plans** (primary → `/billing` or settings billing route) + **Maybe later** (outline)

Server still returns `402` / `PLAN_LIMIT`; client also shows this dialog on mutation error if gate raced.

Invalidate `me.get` after successful creates/archives that change counts (D-43).

---

### Archive confirm Dialogs (D-30–D-33)

**Archive property:**
- Title: **Archive {propertyName}?**
- Body: Explain archive vs permanent delete; list **every affected unit** (label + status) in a scrollable `max-h-48` list; if no units, say so.
- Confirmation: Input requiring exact property name
- CTA: **Archive property** (`Button` destructive) disabled until name matches; Cancel: **Keep property**

**Archive unit:**
- Title: **Archive {unitLabel}?**
- Body: Soft-archive explanation (data retained; hidden from active lists)
- CTA: **Archive unit** destructive; Cancel: **Keep unit**
- No type-name required for single unit (cascade risk is property-level only)

## Layout Patterns

### Portfolio list pages (`/properties`, `/units`)
- Inside landlord app layout with sidebar (`SIDEBAR_NAV` Manage group already lists both)
- Page padding: `px-content` / existing content padding token (`--content-padding: 2rem`)
- Header: `flex items-center justify-between gap-4` — title + primary CTA
- Below header: `md:16` gap then list

### Property detail
- Breadcrumbs above Display title
- Sections stack with `gap-8`; each major block in `Card` or bare section with Heading
- Nested units: `Table` inside Card with CardHeader actions

### Sheets
- Unit form Sheet: side right, width `sm:max-w-md`, padding `p-6`, footer sticky with Cancel + Submit

### Dialogs
- Standard `DialogContent` `sm:max-w-md`; archive property may use `sm:max-w-lg` when unit list is long

### Routes to add (extend `ROUTES`)

```
properties: /properties
propertyNew: /properties/new
propertyDetail: /properties/[propertyId]
propertyEdit: /properties/[propertyId]/edit
units: /units
unitDetail: /units/[unitId]
```
