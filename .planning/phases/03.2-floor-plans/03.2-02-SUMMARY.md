## Deviations from Plan

### Auto-fixed / adjusted

**1. [Rule 3 - Verification tooling] Verified the `permissionProcedure('write')` count with `rg -Fc`, not the plan's `rg -c`**
- **Found during:** Task 3 acceptance-criteria run.
- **Issue:** The criterion `rg -c "permissionProcedure('write')"` treats `(`/`)` as regex groups, so it matches the non-existent literal `permissionProcedure'write'` and returns 0 — a false negative (exactly the D-49 hazard STATE.md records).
- **Fix:** Ran `rg -Fc "permissionProcedure('write')"` (fixed-string) → 6 matches. No code change; the router is correct.

- The plan's own `files_modified` lists no test file, the plan-level frontmatter is `type: execute` (not `type: tdd`, so the plan-level RED/GREEN gate does not apply), and Task 1's acceptance criteria are grep + `typecheck` only.
