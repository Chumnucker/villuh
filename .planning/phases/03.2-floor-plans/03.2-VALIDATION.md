### ⚠ Baseline is RED — every server-test criterion must target one file

`pnpm turbo run test --filter=@villuh/server` **exits non-zero today, before this phase writes a line of code**: 6 failed / 6 passed files, 27 failed / 51 passed tests. The failures are entirely Phase 2 territory (`billing` 7, `plan-limit` 6, `permissions` 4, `audit` 3, `org` 2, `wizard` 5) and Phase 2 is `0/12 Not started`.

`properties.test.ts` (9), `units.test.ts` (8) and `gallery.test.ts` (6) all pass.

**Consequence:** any acceptance criterion phrased as "`pnpm turbo run test --filter=@villuh/server` exits 0" is unsatisfiable and would block the phase forever. Use the single-file form above.

### ⚠ Shell contract (D-50, inherited from 03.1 D-49)

Every command in every plan must run in **Windows PowerShell 5.1**. No `&&`, no `grep`, no POSIX `find`, no `2>/dev/null`, no `rg -E` (that flag is `--encoding`). Use `;`, `rg -F` for literal source text, `Get-ChildItem -Recurse`, and `master` as the git base. **Run every command before recording its result — especially the ones expected to return non-zero**; a malformed command, an unknown flag, and a genuine pass are indistinguishable by exit code alone.

## Sampling Rate

- **After every task commit:** `pnpm turbo run typecheck` (~21s). For server tasks, add `pnpm --filter @villuh/server exec vitest run src/__tests__/floor-plans.test.ts` (~16s).
- **After every plan wave:** `pnpm turbo run lint typecheck` + the four green server suites (`floor-plans`, `properties`, `units`, `gallery`) + `pnpm turbo run test --filter=@villuh/ui`.
- **Phase gate:** all of the above green, plus `pnpm turbo run build --filter=@villuh/landlord-web` exit 0, plus every manual scenario below demonstrated.
- **Max feedback latency:** ~21s.
