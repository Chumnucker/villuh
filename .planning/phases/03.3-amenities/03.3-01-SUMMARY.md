# Phase 03.3 Plan 01: Amenities Data Foundation Summary

The amenities data layer now exists end-to-end: two pgEnums (`amenity_scope`, 38-key `amenity_icon`) built from the same as-const arrays that back the Zod contract, four RLS-isolated Drizzle tables (`organization_amenity` catalog + `property_amenity`/`unit_amenity` assignments + `property_amenity_image` gallery), the complete importable Zod input contract at `@villuh/server/schemas/amenities`, and the hand-authored `0019_amenities.sql` migration applied cleanly to both the dev and `villuh_test` databases. This unblocks every downstream wave-1+ plan in the phase.

## What Was Built

- **Task 1 — Zod contract + enums + export** (`166062f`): `modules/amenities/schemas.ts` declares `AMENITY_SCOPES = ['property','unit','both']` and the exact 38 icon keys from spec §5.1 (`IconStar` default), reuses `TAG_COLOR_KEYS` for `colorKey` (D-04, no new color array), and defines every catalog/property/gallery/unit input schema with inferred types. `enums.ts` gains `amenityScopeEnum`/`amenityIconEnum`; `package.json` exports `./schemas/amenities`. No `amenity_reservation_status` (D-20).
- **Task 2 — Four Drizzle tables** (`a3fb8e7`): `schema/amenities.ts` with `organization_isolation` pgPolicy + `.enableRLS()` on all four tables, nullable catalog FKs with `onDelete: 'set null'`, denormalized `label`/`iconKey`/`colorKey` (NOT NULL defaults, D-12), inert `is_reservable`/`requires_approval` on `property_amenity` only (D-05), and a deliberately thin `unit_amenity` (no description/updatedAt/sortOrder/reservability). Barrel export added. Monorepo typecheck 6/6 green.
- **Task 3 — Migration** (`3f81802`): hand-authored `0019_amenities.sql` (2 enums, 4 tables, 4 RLS enables, 4 policies, catalog unique constraint, both partial unique indexes with `WHERE organization_amenity_id IS NOT NULL` for D-22/D-24, 4 audit triggers). Journal idx 19 appended. Applied to dev (`DATABASE_URL`) and test (`DATABASE_OWNER_TEST_URL`) — both exit 0 (D-27a).

## Deviations from Plan

None — plan executed exactly as written.
