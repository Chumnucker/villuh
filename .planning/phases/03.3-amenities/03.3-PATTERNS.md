**Source:** `floor-plans/service.ts:16-35` `rethrowDuplicateNameAsBadRequest`. **Apply to:** catalog create/update (unique name) and both partial-unique-index inserts (`.catch(rethrow...)`).

**Source:** `tags/router.ts:158-179` (attach copies `label/iconKey/colorKey` from catalog). **Apply to:** every `property.add`/`unit.add`/`attach`/`set`/`bulkAdd` — display never joins (D-23).

**Source:** `gallery-manager.tsx:187-225` + `@villuh/ui/utils` (`acceptImageFiles`, `uploadPresignedPut`). **Apply to:** the extracted `GalleryManager` with `cap = 10`.

### URL-backed overlays
**Source:** `createOverlays` (`properties.overlays.ts`), `EntityOverlayHandle` + `OverlayBody` gating (`unit-form-sheet.tsx`). **Apply to:** amenity sheet + catalog dialog. **Forbidden:** `useState` overlay trios (D-15).
