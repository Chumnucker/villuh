## Decisions Made
- **bulkAdd ownership check via set-size comparison:** resolve `unitIds` and `organizationAmenityIds` in one query each and compare against the deduped input size; any missing id → `NOT_FOUND`. Keeps ownership explicit on top of RLS without per-id round trips.
- **Grouping in memory, not SQL:** `listByProperty` does one joined SELECT and groups by `unitId` in JS — still a single DB query (satisfies D-33's no-N+1 requirement) while returning the shape the units table wants.
