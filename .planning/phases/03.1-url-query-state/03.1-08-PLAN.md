<shell_contract>
**All commands below run in Windows PowerShell 5.1 (D-49).** No `&&`, no `grep`, no POSIX `find`, no `diff`.

- Sequence with `;`. Where the next command must only run on success: `A; if ($LASTEXITCODE -ne 0) { exit 1 }; B`.
- Search with `rg`. Use `rg -qF` / `-cF` / `-nF` whenever the pattern is literal source text — `(`, `)`, `[`, `]`, `{`, `}`, `$` are regex metacharacters, and unescaped they match the wrong thing rather than erroring.
- Alternation is `a|b`, never `a\|b` (rg reads `\|` as a literal pipe).
- `-E` is **not** extended-regex in rg, it is `--encoding`. `rg -qE` exits `2` with `unknown encoding` — which satisfies a "returns non-zero" check and becomes a silent pass. Regex is rg's default; drop the `E`.
- Write inner double quotes as `\"` — PowerShell 5.1 strips them before the argument reaches a native exe. **Exception:** a pattern that *begins* with `\"` and also contains a space is split into two argv entries, so drop the quotes and match the inner text instead.
- No POSIX `diff` — in PowerShell it aliases `Compare-Object`, which compares the two path *strings* rather than the files. Use `Compare-Object (Get-Content a) (Get-Content b)`.
- **No glob in a path argument.** PowerShell does not expand globs for native commands, so `rg -n 'X' apps/*/app/layout.tsx` hands rg a literal `*` and exits `2` (`os error 123`). Name the files, or use rg's own `--glob` flag.
- Git ranges use `master`.

**These are rules about shell syntax, never about quoted source text.** A pattern like `rg -qF 'a.id === b.id && a.desc === b.desc'` is TypeScript inside an argument and keeps its `&&`; the same goes for `;`, `|` and `$` inside a pattern.

**Run every command before recording its result, especially the ones expected to return non-zero.** A malformed command, an unknown flag, and a genuine pass are indistinguishable by exit code alone. And if a criterion asserts a token is absent from a file whose mandated comments contain that token, it is unsatisfiable as written — strip comments first:

```powershell
$code = (Get-Content $f) -replace '//.*$','' | Where-Object { $_ -notmatch '^\s*\*' }
```
