# Phase 03.1 Plan 05: Units Table URL-State Migration Summary

**The only DataTable in the app now stores its search, filters, sort, and pagination in the URL. `createUnitsFilterFields` became a single `defineTable` config (`units.table.ts`); the `useMemo(filterFields) + useDataTableQuery` pair plus both option queries collapsed into one `useDataTableQueryState(unitsTable, { hide })` call; `units-filters.tsx` is deleted. No DataTable primitive, toolbar, or column def was touched.**

## Performance

- **Duration:** ~30 min
- **Completed:** 2026-08-13
- **Tasks:** 3 of 3 (Task 3 = human-verify checkpoint, approved)
- **Files:** 4 (1 created, 2 modified, 1 deleted)

## What was built

### Task 1 — `units.table.ts`
The units table top-to-bottom in one `.ts` config: `defineTable("units", null, …)` with unprefixed URL keys, `sortable` mirroring `UNIT_SORT_KEYS`, and four fields (`property`, `status`, `baseRent`, `squareFootage`) carrying their operator allow-lists, `server` param mappings (incl. `excludePropertyIds`/`excludeStatusIds`/`statusEmpty`/`baseRentCents`/`squareFootageEmpty`), and the `dollarsToCents` transform — a faithful transliteration of `createUnitsFilterFields`. Property/Status options come from `useOptions(hidden)` hooks that gate their tRPC query on `enabled: !hidden` (D-22), with the `if (properties?.length)` emptiness guards removed (D-23).

### Task 2 — `UnitsList` migration
Swapped `useDataTableQuery` → `useDataTableQueryState(unitsTable, { hide })`, with `hide` = module-scope `HIDE_PROPERTY`/`HIDE_NOTHING`. Removed the local `properties.list`/`unitStatuses.list` queries and the `filterFields` useMemo (both moved into the config). The `propertyIds: [lockedPropertyId]` override still spreads after `...serverInput`. Overlay `useState` trio and the entire `<DataTable>` prop list unchanged. Deleted `units-filters.tsx` and its re-export.

### Task 3 — human-verify checkpoint
Approved by the user: clean URL, search commits after the debounce (D-41 chain holds), readable `:`/`,` filters, sort/page/size, cold-restore from a pasted URL, single-back-press history, property-tab scoping with no `properties.list` request, and hand-edit tolerance.
