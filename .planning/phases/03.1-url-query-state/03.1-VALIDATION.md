# Phase 03.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `03.1-RESEARCH.md` § Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework (existing)** | `vitest@4.1.5` — **`apps/server` only**; no frontend test infrastructure exists anywhere in the monorepo (D-46) |
| **Framework (this phase)** | `vitest` **node-environment** project in `packages/ui`, pure parser tests only |
| **Config file** | `packages/ui/vitest.config.ts` — **does not exist; Wave 0 creates it** |
| **Quick run command** | `pnpm turbo run test --filter=@villuh/ui` |
| **Full suite command** | `pnpm turbo run test` |
| **Type gate** | `pnpm turbo run typecheck` — exists in every workspace |
| **Lint gate** | `pnpm turbo run lint` — exists; catches a mis-scoped D-22 eslint disable (`rules-of-hooks` is `error` in `packages/ui`) |
| **Build gate** | `pnpm turbo run build --filter=@villuh/landlord-web` — the only check that catches a static-generation / CSR-bailout regression (D-48) |
| **Estimated runtime** | ~5s unit; ~60s full turbo run |

**Explicitly out of scope:** jsdom, `@testing-library/react`, `user-event`, `withNuqsTestingAdapter`. Component-level behaviour is manually verified this phase.

---

## Sampling Rate

- **After every task commit:** `pnpm turbo run test --filter=@villuh/ui; pnpm turbo run typecheck`
- **After every plan wave:** `pnpm turbo run lint test typecheck` + `pnpm turbo run build --filter=@villuh/landlord-web`
- **Before `/gsd-verify-work`:** full suite green **and** all manual scenarios below demonstrated
- **Max feedback latency:** ~5 seconds (unit), ~60 seconds (wave gate)

## Manual-Only Verifications

No frontend component-test toolchain exists (D-46), so all component and browser behaviour is manual. Every row must be demonstrated before phase sign-off.

| Behaviour | Decision | Why Manual | Test Instructions |
|-----------|----------|------------|-------------------|
| Cold-load a URL carrying both filters and an open sheet restores both | D-06, D-18 | Requires a real browser navigation | Paste a filtered `/units?...&unit.form=<id>` URL into a fresh tab |
| Search commits exactly one URL write ~300 ms after the last keystroke | D-27, D-41 | Proxy for setter referential stability without RTL | Type in the search box, watch the address bar and Network tab |
| Twelve filter changes **with no overlay interaction** require one back press | D-26, D-42 | Browser history semantics | Apply 12 filter changes, press Back once |
| Back closes an open overlay without clearing filter state | D-12 | Browser history semantics | Open a sheet on a filtered table, press Back |
| Invalid / non-existent id in `?unit.form=` renders the not-found state, not a blank sheet | D-06, D-15 | Requires real tRPC error round-trip | Hand-edit the URL to a bogus id |
| `/units` and the property Units tab do not cross-talk | D-29 | Cross-route behaviour | Filter one, navigate to the other |
| Untouched table produces a bare URL with no query string | D-20 | Visual URL inspection | Load `/units` fresh |
| Radix exit animation survives a URL-driven close | D-12 | Visual | Close a sheet via Escape, overlay click, and Back |
| No overlay query fires on an unrelated page | D-36 | Network inspection | Open `/settings`, confirm the Network tab shows none of `units.get`, `properties.get`, `tags.listOrganizationTags`, `properties.list`, `unitStatuses.list`. The last two are ungated by design — `UnitFormBody` relies on Radix not rendering `SheetContent` while closed, the phase's only structural rather than `enabled`-flag gate — so this row is the sole check on them |
| Gallery lightbox keeps its shared-element zoom from a thumbnail click | D-32 | Visual animation | Click a gallery photo |
| Gallery lightbox degrades to a plain fade on cold deep link | D-33 | Visual animation | Paste a `gallery.photo=<imageId>` URL into a fresh tab |

**Not tested — unreachable state:** the `FORBIDDEN` branch of `<OverlayBody>` (D-44). RLS converts cross-organization access to `NOT_FOUND` before any authorization check runs, so the branch is implemented for correctness but cannot be exercised.
