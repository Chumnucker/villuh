## Decisions Made

- **`passWithNoTests` deliberately left at its default `false`.** The cheap way to make Task 1's last criterion pass was to set it `true`, but that would make a future mis-scoped `include` glob report green forever — precisely the silent-pass failure mode D-49 was written to stop. The criterion is met from Task 2 onward instead.
- **Pre-existing lint and test failures in `@villuh/auth`, `@villuh/api`, `@villuh/landlord-web`, and `@villuh/server` were logged, not fixed.** Each is unrelated to URL query state and fixing them would mean scaffolding two eslint configs, changing Phase 03 hero-image load behaviour, and provisioning live Stripe credentials. See `deferred-items.md`.
- **`SingleParserBuilder<T>` types `eq` as required** (`Required<SingleParser<T>>`), so the contract test calls `parser.eq(a, b)` directly rather than the plan's `p.eq!(...)`. Same assertion, no non-null operator needed.
