**Step 1.3 — Create `packages/web/lib/auth-server.ts` as a STANDALONE Better Auth instance:**

CRITICAL ARCHITECTURE CONSTRAINT: `packages/web/lib/auth-server.ts` MUST NOT import from `@villuh/server`. Importing the Hono server's auth instance into the Next.js app would bundle Stripe + Drizzle + the full Better Auth Stripe plugin into the Next.js build, collapsing the two-deployment architecture (CLAUDE.md Stack: Next.js 16 on one host, Hono 4 on Railway). Per RESEARCH.md, Next.js middleware that needs to read sessions creates its OWN minimal `betterAuth()` instance pointed at the same Postgres DB and the same `BETTER_AUTH_SECRET`, with NO Stripe/Resend/org plugins (those plugins are server-only and not needed for session reads).

```typescript
// packages/web/lib/auth-server.ts
// Standalone minimal Better Auth instance for Next.js middleware (Node.js runtime).
// Reads sessions from the same Postgres DB and signs them with the same BETTER_AUTH_SECRET
// as the Hono server in packages/server. NO Stripe/Resend/org plugins — session reads only.
import 'server-only'
import { betterAuth } from 'better-auth'
import { drizzleAdapter } from 'better-auth/adapters/drizzle'
import { drizzle } from 'drizzle-orm/postgres-js'
import postgres from 'postgres'
import * as authSchema from '@villuh/db/schema/auth'

if (!process.env.DATABASE_APP_URL) {
  throw new Error('DATABASE_APP_URL is required for Next.js middleware Better Auth instance')
}
if (!process.env.BETTER_AUTH_SECRET) {
  throw new Error('BETTER_AUTH_SECRET is required (must match the Hono server value)')
}

const client = postgres(process.env.DATABASE_APP_URL, { max: 2 })
const db = drizzle({ client, schema: authSchema })

export const auth = betterAuth({
  baseURL: process.env.BETTER_AUTH_URL ?? 'http://localhost:3001',
  secret: process.env.BETTER_AUTH_SECRET,
  database: drizzleAdapter(db, { provider: 'pg', schema: authSchema }),
  // No emailAndPassword/socialProviders/plugins blocks — middleware only reads sessions.
  // Better Auth's getSession works without these because session validation only needs
  // the secret + database adapter. Mutations (signup, signin, etc.) hit the Hono server's
  // full instance via /api/auth/* (proxied through NEXT_PUBLIC_API_URL).
})

export type Session = typeof auth.$Infer.Session
```

**Why this works:** Better Auth's `auth.api.getSession({ headers })` reads the signed session cookie, verifies the HMAC with `secret`, and looks up the session row in the `session` table via the database adapter. No plugin code paths are exercised for read-only session validation. The Hono server holds the full instance (Stripe/Resend/org plugins) — middleware just shares the secret and DB.

**DO NOT** add `@villuh/server` as a dependency of `@villuh/web`. **DO NOT** add a `./auth` export to `packages/server/package.json`. The two packages share schema (`@villuh/db`) and an env contract (BETTER_AUTH_SECRET), nothing else.

**Step 2.6 — Create `packages/web/modules/auth/components/reset-password-form.tsx`:**

Reads token from `useSearchParams`. Two PasswordInput fields (new + confirm). Mismatch sets `aria-invalid` on confirm field. On success, replace card with "Password updated" + LinkButton → /login. Invalid token: detect `error.message` containing "expired" or "invalid" and show "Link expired" card with `LinkButton` "Request a new one" → `/forgot-password`.

```tsx
"use client"

import { useState } from "react"
import { useSearchParams } from "next/navigation"
import { Button, LinkButton } from "@/modules/common/ui/button"
import { PasswordInput } from "@/modules/common/ui/input"
import { Field, FieldLabel, FieldError } from "@/modules/common/ui/field"
import { authClient } from "@/lib/auth-client"
import { toast } from "sonner"
import { AuthCard } from "./auth-card"

export function ResetPasswordForm() {
  const params = useSearchParams()
  const token = params.get("token") ?? ""
  const [newPassword, setNewPassword] = useState("")
  const [confirm, setConfirm] = useState("")
  const [mismatch, setMismatch] = useState(false)
  const [done, setDone] = useState(false)
  const [expired, setExpired] = useState(false)
  const [loading, setLoading] = useState(false)

  if (done) {
    return (
      <AuthCard title="Password updated" description="You can now sign in with your new password.">
        <LinkButton href="/login" variant="default" className="w-full">Sign in</LinkButton>
      </AuthCard>
    )
  }

  if (expired) {
    return (
      <AuthCard
        title="Link expired"
        description="This reset link has expired or already been used."
      >
        <LinkButton href="/forgot-password" variant="link">Request a new one</LinkButton>
      </AuthCard>
    )
  }

  return (
    <AuthCard title="Set a new password">
      <form
        className="flex flex-col gap-4"
        onSubmit={async (e) => {
          e.preventDefault()
          if (newPassword !== confirm) {
            setMismatch(true)
            return
          }
          setMismatch(false)
          setLoading(true)
          const { error } = await authClient.resetPassword({ newPassword, token })
          setLoading(false)
          if (error) {
            const msg = (error.message ?? "").toLowerCase()
            if (msg.includes("expired") || msg.includes("invalid")) {
              setExpired(true)
              return
            }
            toast.error("Something went wrong. Please try again.")
            return
          }
          setDone(true)
        }}
      >
        <Field>
          <FieldLabel>New password</FieldLabel>
          <PasswordInput value={newPassword} onChange={(e) => setNewPassword(e.target.value)} required minLength={8} autoComplete="new-password" />
        </Field>
        <Field>
          <FieldLabel>Confirm password</FieldLabel>
          <PasswordInput value={confirm} onChange={(e) => setConfirm(e.target.value)} required minLength={8} autoComplete="new-password" aria-invalid={mismatch || undefined} />
          {mismatch && <FieldError>Passwords do not match</FieldError>}
        </Field>
        <Button type="submit" size="lg" className="w-full" disabled={loading}>
          Set new password
        </Button>
      </form>
    </AuthCard>
  )
}
```
